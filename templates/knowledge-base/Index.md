# Claude's notes

Claude's own knowledge base about me and my world, kept up to date by Claude without being asked, and meant to grow over time. I don't need to maintain anything here.

Claude's built-in memory holds the short core that every chat needs. This space holds the detail, the history and the archive. Memory lines can point here.

## How to use this space
- Read this index first, then open only the folder or note you need. Don't read whole folders.
- One note per subject. Update an existing note rather than starting a near-duplicate.
- Each note starts with a `description:` line in its frontmatter, so folder listings tell you what's inside without opening every note.
- Record anything worth reusing as it comes up in a chat: facts about me and the people in my life, decisions and why, outcomes, how things turned out, and findings or comparisons researched for me. No passing details.
- Don't copy ID, card or bank numbers; link to the document in Files instead.
- Nothing here is ever deleted. When a note is finished or outdated, write a copy to `Archive/` named `YYYY-MM-DD Title.md` (the date it was archived), then cut the live note down to one line linking to the archived copy.
- Create a folder when its first note is needed. When a folder passes about 15 notes, give it its own `Index.md` and split it into subfolders.
- Keep this index short: the folders, plus the few notes that matter most. Not every note.
- Use `[[wikilinks]]` between notes.
- Write only what I said or what a document, email or my own notes state. Anything Claude infers or generalises gets "(inferred)" on that line, and goes on the next review's list of questions until I confirm or correct it.

## Folders
- `People/`: people in my life, one note each
- `Topics/`: my tastes, habits and setup, one note per topic
- `Ongoing/`: things in progress, such as claims, purchases and projects
- `Reviews/`: weekly review logs, named `YYYY-MM-DD Weekly review.md`
- `Archive/`: finished or outdated notes, dated
